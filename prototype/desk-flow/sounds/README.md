# 효과음 파일 넣는 곳

지금은 파일 없이 코드로 만든 소리가 나요. 실제 녹음 파일로 바꾸고 싶으면:

1. 이 폴더에 아래 이름 그대로 mp3 파일을 넣어요.
2. `list.json` 에 넣은 파일 이름을 적어요. 예: `["key", "cup", "ring"]`

| 파일 이름 | 언제 나는 소리 |
|---|---|
| key.mp3 | 키보드 키 하나 누를 때(한 번 클릭에 7번 남) |
| cup.mp3 | 컵이 살짝 떴다가 책상에 닿을 때 |
| drawerOpen.mp3 | 서류 서랍 열 때 |
| drawerClose.mp3 | 서류 서랍 닫을 때 |
| ring.mp3 | 전화벨 한 번(2.4초마다 반복) |
| pickup.mp3 | 수화기 들 때(전화 받기) |
| hangup.mp3 | 수화기 내려놓을 때 |
| switch.mp3 | 스탠드 스위치 |

목록에 없는 이름은 코드로 만든 소리가 그대로 나요. 소리는 화면 왼쪽 아래 ♪ 버튼으로 켜야 들려요.

## 배경음

`VIN_portfolio_bgMusic.mp3` — ♪ 버튼으로 소리를 켜면 반복 재생돼요(효과음보다 작게, 전화 장면에서는 더 작게). 다른 곡으로 바꾸려면 같은 이름으로 덮어쓰면 돼요.
