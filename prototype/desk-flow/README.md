# VIN 책상 흐름 (3D 프로토타입)

three.js 책상 장면 하나로 이어지는 포트폴리오 흐름.
Home → Work(모니터: 작업물 목록) → About(서랍: 이력서·자기소개서 등 서류) → Contact(전화) → Ending(퇴근)

- 실행: `index.html`을 정적 서버로 열기 (예: `npx serve prototype/desk-flow`)
- `models.js`: 3D 모델(스탠드·전화기·수화기·책상·의자) base64
- `models/*.glb`: 새 모델(웹용으로 줄인 것) — iMac 2021·매직 키보드·매직 마우스·빨간 서랍장·플립 시계·커피잔·펜꽂이
  - 원본은 `public/models/src/`(저장소에 올리지 않음). 줄이면서 쓰지 않는 텍스처(광택·요철) 제거, 텍스처는 최대 1024px WebP
  - 서랍장은 원본에서 한 덩어리였던 서랍을 `drawer_0`(위)·`drawer_1`·`drawer_2`(아래, 서류 서랍)로 나눠 둠
  - 크기는 실제 치수(cm)로 맞춤(iMac 폭 54.7 · 키보드 41.9 · 서랍장 높이 69 등). iMac은 흰색, 서랍장 서랍은 블루톤(테마 색 CM)
  - 서랍 앞부분은 3.5cm 두께로 얇게(`DRT`), 서류 서랍은 폴더가 다 보일 만큼만 열림
- 플립 시계: 방문자 컴퓨터의 실제 시각을 보여 줌(분 단위). Ending에서는 지금 시각 → 18:00으로 빠르게 흐름(18시 이후면 그대로)
- 스탠드 불빛: 갓 안 전구에서 나와 갓 입구 번짐 → 아래로 옅어지는 빛줄기 → 책상 위 따뜻한 빛 웅덩이. 화면 스타일 처리 뒤에 겹쳐 그리고, 물건 뒤의 빛은 가려짐
- 효과음(♪ 소리 켜기일 때): 키보드 클릭 → 키 7개가 눌리며 타닥타닥 / 컵 클릭 → 떴다 내려앉으며 '팅' / 서류 서랍 열기·닫기 / 전화벨(울리는 동안) / 전화 받기 → 수화기 드는 소리, 끊기 → 내려놓는 소리 / 스탠드 스위치
  - 지금은 코드로 만든 소리. 실제 녹음 파일로 바꾸려면 `sounds/README.md` 참고(파일을 넣고 `sounds/list.json`에 이름 적기)
- 다운로드 파일: 같은 폴더에 `resume.pdf`/`resume.hwp`, `cover-letter.pdf`/`cover-letter.hwp` 를 넣으면 About 서랍의 이력서·자기소개서 창에서 다운로드 버튼이 동작(PDF가 있으면 PDF 먼저). 주소·전화번호·생년월일이 든 파일은 누구나 받을 수 있으니 지우고 올리기
- 프로젝트 표지: `covers/이름.jpg`(상세용 2560px, 글자 들어간 구성), `covers/이름-sm.jpg`(모니터 배경용 1280px)
- 모니터 WORK 화면은 화면 스타일(알갱이·명암) 처리를 거치지 않고 맨 위에 원래 그림 그대로 그림(선명하게). 큰 화면에서는 2560×1440으로 그림. 표지 위 회색 막은 12%로 옅게
- 명함 이미지: `card-front.jpg`(앞), `card-back.jpg`(뒤). 명함을 열면 한 바퀴 돌며 나오고, 누르면 앞↔뒤로 뒤집힘
- EmailJS 키는 `.env.local`에만 보관 (저장소에 올리지 않기)
- 화면 스타일: 기본은 매트캡 v2(`matcap/v2/` 금속·플라스틱·종이). 비교용으로 주소 끝에 `?style=basic`(평면 일러스트), `?style=retro`(레트로), `?style=matcap`(매트캡 v1)
- ABOUT 서류: 폴더 뒤에 서류 첫 장이 꽂혀 있고, 클릭하면 종이가 폴더에서 스르륵 올라와 화면 가운데로 날아옴(살짝 휜 진짜 종이, 그림자, 여러 장이면 ‹ › 또는 종이 클릭으로 넘김)
  - 문서 이미지: `docs/resume.png`(있으면 우선) → `docs/resume-1.jpg`(개인정보 모자이크판), `docs/cover-1.jpg`·`docs/cover-2.jpg`. 가로 이미지는 가로 A4 종이로 나옴
  - 나머지 서류(My Story 등)는 글을 A4 종이에 자동 조판
- 인트로: 블루톤 화면에 멘트가 타이핑되고 로딩바·% 표시
