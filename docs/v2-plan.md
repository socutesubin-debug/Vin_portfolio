# VIN 포트폴리오 V2 기획

> V2 작업은 모두 `v2` 브랜치에서 진행한다. `main` 브랜치(V1, 서랍장 스크롤 사이트)는 건드리지 않는다.
> V2 작업을 할 때는 이 문서를 먼저 참고한다. 기획이 바뀌면 이 문서부터 고친다.

## 콘셉트

**"잠시 자리를 비운 디자이너의 작업실"**

사람이 없는 작업실을 방문자가 둘러보는 구조다. 방문자는 스크롤로 작업실 안을 이동하며 책상, 모니터, 서랍장, 전화기를 차례로 본다.

## 1단계: 카메라 이동 프로토타입 ✅ 완료 (2026-10-28)

### 범위

- 카메라 이동만 만든다. 인터랙션(의자 드래그, 조명, 전화기, 메일 전송)은 만들지 않는다.
- 3D 모델 대신 임시 도형(box, cylinder, plane)으로 공간을 구성한다.
- 나중에 GLB 모델로 쉽게 바꿀 수 있게 오브젝트마다 컴포넌트를 나눈다.

### 공간 구성 (임시 도형)

| 위치 | 오브젝트 |
|---|---|
| 공간 | 바닥, 뒷벽, 창문(벽에 뚫린 밝은 사각형) |
| 가구 | 책상(상판 + 다리 4개), 의자 |
| 책상 위 | 모니터, 키보드, 마우스, 스탠드 조명, 명함, 전화기 |
| 책상 아래 오른쪽 | 서랍장(파란색 `#1e278f`, 서랍 3칸) |

### 4개 장면 (카메라 위치)

| 순서 | 장면 | 카메라 구도 |
|---|---|---|
| 1 | HOME | 작업실 전체를 정면에서 보는 넓은 시점. 약간 위에서 내려다본다. |
| 2 | ABOUT | 모니터를 정면(눈높이)에서 본다. 모니터가 화면 중앙에 크게, 아래로 키보드·마우스까지 보인다. |
| 3 | WORK | 서랍장을 정면에서, 살짝 위에서 아래로 가까이 내려다본다(서랍 속 프로젝트가 잘 보이게). |
| 4 | CONTACT | 책상 위, 오른쪽 앞 35도 측면 구도. 전화기가 화면 중앙에 온다. |

> 처음 기획에서 바뀐 점(사용자 피드백 반영): HOME은 비스듬한 시점 → 정면, ABOUT은 정면·키보드까지,
> WORK는 서랍장 정면을 위에서 내려다보는 근접 구도, CONTACT는 45도 → 35도. 서랍장은 항상 정면으로 본다.

### 동작

- 스크롤하면 카메라 위치와 바라보는 지점(target)이 장면 사이를 부드럽게 보간된다. 끊기지 않고 이어지는 느낌이 중요하다.
- 상단 메뉴(HOME / ABOUT / WORK / CONTACT)를 누르면 해당 장면으로 부드럽게 스크롤 이동한다.
- 현재 장면에 해당하는 메뉴에 밑줄을 표시한다.
- 장면마다 카메라 위치와 target 값을 한 곳(설정 객체)에 모은다. 숫자만 바꿔서 조정할 수 있어야 한다.
- 개발용으로 화면 구석에 현재 카메라 좌표를 보여주는 작은 패널을 둔다. 설정으로 끌 수 있어야 한다.

### 기술

- 기존 스택을 따른다: React 19 + TypeScript + Vite, React Three Fiber + drei, GSAP ScrollTrigger, zustand.
- 모바일에서도 깨지지 않게 화면 비율에 따라 카메라 화각(fov)을 조정한다.

### 완료 기준

- 스크롤을 처음부터 끝까지 내리면 4개 장면이 순서대로 자연스럽게 이어진다.
- 메뉴 클릭으로 어느 장면이든 바로 이동할 수 있다.
- 로컬에서 실행해 확인하는 방법을 안내한다.

### 설계 원칙

- 각 오브젝트 컴포넌트는 `position` 등 배치 값만 받고 내부에서 도형을 그린다. GLB로 바꿀 때 컴포넌트 내부만 교체하면 된다.
- 카메라 값은 GSAP가 일반 객체에 쓰고 `useFrame`에서 읽는다(스크롤마다 React 리렌더 없음). V1과 같은 방식이다.
- 위치와 target을 같은 타임라인에서 함께 보간해 시선이 튀지 않게 한다.
- 뒤로 스크롤하면 이전 장면으로 그대로 돌아온다.

### 1단계 구현 메모

- 모바일 대응: 화면이 좁아지면 세로 화각을 최대 `maxFov`(72°)까지 넓히고, 그래도 `minKeepAspect`만큼의 가로 시야가 안 나오면 카메라를 target에서 뒤로 뺀다. 개발 패널에 `거리 ×n`으로 표시된다.
- 개발 패널에 보이는 position/target은 `scenes.ts`에 넣을 설정값 그대로다(모바일에서 뒤로 뺀 거리는 반영 전 값).
- 조명 갓이 ABOUT 장면에서 모니터를 가리지 않도록 스탠드는 왼쪽 앞으로 뻗게 돌려 두었다.
- 의자는 ABOUT 정면 시점을 가리지 않도록 책상 왼쪽으로 빼 두었다(자리를 비운 느낌).
- WORK 시점에서는 책상 앞쪽 모서리가 서랍장 윗면 일부를 가린다. 서랍을 여는 단계에서는 서랍이 앞으로 충분히 나오게 한다.

## 2단계: WORK 장면 — 서랍과 프로젝트 보기 ✅ 완료 (2026-10-28)

### 요구사항

**서랍장**
- 임시 서랍장을 실제 디자인으로 바꾼다. 참고: 이전에 받은 `VIN 서랍장` index.html — 파란 도장(`#1e278f`, 클리어코트) + 크롬 레일(모서리·서랍 사이 파이프와 구슬 마감) + 아치형 받침 + 라벨 프레임과 컵 손잡이.
- 모든 프로젝트는 **맨 위 서랍 하나**에 들어 있다. 맨 위 서랍 라벨 프레임에 **"WORK"**라고 쓴다.
- 맨 위 서랍에 마우스를 올리면 살짝 나오고, 클릭하면 열린다.
- 가운데와 아래 서랍은 잠겨 있다. 클릭하면 덜컥 하고 살짝 흔들리기만 하고 열리지 않는다.
- 나중에 이스터에그를 넣을 수 있게, 서랍마다 열림/잠김을 설정에서 바꿀 수 있다.

**서랍 안**
- 열린 서랍 안에 프로젝트 파일(서류 폴더 모양)이 세워져 꽂혀 있다. 폴더 탭에 프로젝트 이름이 보인다.
- 카테고리(**UX/UI**, **브랜딩·그래픽**, **패션**)는 칸막이와 폴더 탭 색깔로 구분한다. 칸막이 윗부분에 카테고리 이름이 적힌 인덱스 탭을 붙인다.
- 서랍이 열리면 카메라가 서랍 안을 내려다보는 각도로 부드럽게 이동한다.
- 폴더에 마우스를 올리면 살짝 위로 올라온다.
- 프로젝트 개수가 바뀌면 칸막이 위치와 폴더 간격이 자동으로 맞춰진다.

**프로젝트 상세**
- 폴더를 클릭하면 2D 전체 화면 오버레이로 상세가 열린다: 제목, 한 줄 소개, 역할, 기간, 대표 이미지, 본문.
- 닫기 버튼이나 ESC로 서랍 화면으로 돌아온다.
- 프로젝트 내용은 `src/v2/data/projects.ts` 한 파일에 모은다. 이 파일만 고치면 프로젝트를 추가·수정할 수 있다. 지금은 카테고리별 임시 프로젝트 2~3개(임시임이 드러나는 이름과 문구).

**완료 기준**
- WORK 장면에서 서랍 열기 → 폴더 고르기 → 상세 보기 → 돌아오기가 끊김 없이 이어진다.
- 모바일에서는 마우스 올리기 대신 탭으로 동작한다.

### 설계 결정

- **크기**: 참고 서랍장은 높이 약 1.5m(받침 포함)라 책상 밑(상판 아래 0.71m)에 들어가지 않는다. 디자인 비율을 그대로 두고 전체를 축소해 책상 아래에 맞춘다(폭 약 0.46m, 높이 약 0.64m). 서랍 안 깊이는 폴더가 들어갈 만큼 확보한다.
- **크롬 반사**: 크롬이 크롬답게 보이려면 주변 반사가 필요해서 장면에 RoomEnvironment 반사광을 약하게 추가한다(다른 물체 밝기는 크게 바뀌지 않게 세기를 낮춘다).
- **서랍이 책상에 가리지 않게**: 서랍장을 책상 앞쪽 모서리 가까이로 당기고, 서랍은 거의 끝까지(풀 익스텐션) 빠져나오게 해서 내려다볼 때 폴더가 책상 상판에 가리지 않게 한다.
- **서랍 설정**: `src/v2/config/cabinet.ts`에 서랍 3칸(위·가운데·아래)의 라벨, 잠김 여부, 들어 있는 내용을 둔다. 잠김을 `false`로 바꾸면 그 서랍도 열린다(이스터에그 자리).
- **칸막이·폴더 자동 배치**: 서랍 안 깊이를 "칸막이 + 폴더" 개수로 나눠 같은 간격으로 앞에서부터 꽂는다. 탭은 왼쪽·가운데·오른쪽으로 번갈아 붙여 뒤쪽 탭도 보이게 한다. 카테고리 색은 `projects.ts`에서 정한다.
- **카메라**: 스크롤 카메라 위에 "서랍 시점"을 덮어쓰는 방식. 서랍이 열리면 서랍 안을 내려다보는 시점으로 부드럽게 옮겨 가고, 닫히면 스크롤 카메라로 돌아온다. 시점 값은 `scenes.ts`의 `DRAWER_VIEW`에서 숫자로 조정한다.
- **스크롤과의 관계**: 서랍이 열린 채로 스크롤해서 WORK를 벗어나면 서랍이 자동으로 닫힌다. 상세 오버레이가 열려 있는 동안에는 배경 스크롤을 잠근다.
- **상태 소유**: 열린 서랍·hover·선택 프로젝트는 zustand 스토어 한 곳에서 관리한다. 서랍·폴더 움직임은 `useFrame`에서 목표값으로 부드럽게 따라간다(매 프레임 React 리렌더 없음).
- **모바일**: 터치 기기에서는 hover가 없으므로 서랍은 탭 한 번에 열리고, 폴더는 탭하면 살짝 올라왔다가 상세가 열린다.
- **닫기**: 서랍이 열려 있으면 화면 아래에 "서랍 닫기" 버튼을 보여준다(모바일에서도 쉽게 닫도록). ESC로도 닫힌다.
- **접근성**: 키보드 사용자를 위해 WORK 장면에서만 쓰는 숨김 버튼 목록(서랍 열기 → 프로젝트)을 둔다. 상세 오버레이는 열릴 때 닫기 버튼으로 포커스, 닫히면 원래 위치로 포커스를 돌려준다.

## 3단계: WORK 장면 — 인덱스 카드, 파일 뽑아보기, 전체 보기 ✅ 완료 (2026-10-29)

> 2단계의 "서랍 안"과 "프로젝트 상세"를 아래 내용으로 바꾼다. 서랍장·잠긴 서랍·서랍 시점은 2단계 그대로.

### 요구사항

**서랍 안** (레퍼런스: 사진 인덱스 박스)
- 열린 서랍 안에 프로젝트 파일 카드가 세워져 빽빽하게 꽂혀 있다. 카드 윗부분 탭에 **프로젝트 이름과 연도**가 보인다.
- 카테고리(UX/UI, 브랜딩·그래픽, 패션)는 **칸막이**로 구분하고, 칸막이 탭에 카테고리 이름을 쓴다.
- 카메라가 서랍 안을 내려다보는 각도로 부드럽게 이동한다. 카드에 마우스를 올리면 살짝 위로 올라온다.
- 프로젝트 개수가 바뀌면 칸막이 위치와 카드 간격이 자동으로 맞춰진다.

**파일 뽑아보기** (레퍼런스: Neil Young 아카이브 폴더)
- 카드를 클릭하면 서랍에서 위로 쑥 뽑혀 나와, 화면 가운데에 살짝 기울어진 서류 폴더처럼 놓인다.
- 폴더 위: 타자기 느낌의 정보 카드(프로젝트명, 역할, 기간, 사용 툴, 한 줄 소개), 클립으로 꽂은 대표 이미지, 포스트잇 "자세히 보기 →"(클릭 시 상세 페이지).
- 폴더 바깥 클릭 또는 ESC → 폴더가 다시 서랍으로 들어간다.
- 폴더는 HTML/CSS로 띄운다. 3D 카드가 뽑혀 올라가는 움직임과 HTML 폴더가 이어지게 한다.

**전체 보기** (레퍼런스: Unseen Studio Selected Projects)
- 서랍 화면에 "전체 보기" 버튼 → 2D 그리드 화면.
- 카테고리 필터 칩: All, UX/UI, 브랜딩·그래픽, 패션. 칩마다 프로젝트 개수.
- 2열 그리드 카드(대표 이미지 + 제목 + 한 줄 설명), 모바일 1열.
- 카드 클릭 → 상세 페이지. "서랍으로 돌아가기" 버튼으로 서랍 화면 복귀.

**프로젝트 상세**
- 2D 페이지: 제목, 한 줄 소개, 역할, 기간, 사용 툴, 대표 이미지, 본문.
- 폴더 미리보기와 그리드 양쪽에서 같은 상세 페이지로 연결된다. 상세를 닫으면 열었던 화면(폴더/그리드)으로 돌아간다.
- 내용은 `src/v2/data/projects.ts` 한 파일에서 관리한다(연도 `year`, 사용 툴 `tools` 추가). 카테고리별 임시 프로젝트 2~3개.

### 설계 결정

- **카드 모양**: 본체와 둥근 탭이 한 장으로 이어진 인덱스 카드(크림색). 탭 위치는 세 군데를 돌아가며 써서 뒤 카드 탭도 보이게 한다. 탭 위쪽에 카테고리 색 띠를 얇게 넣는다.
- **칸막이**: 짙은 남색 판 + 카테고리 색 인덱스 탭(카테고리 이름).
- **뽑기 연출 이어붙이기**: 클릭하면 3D 카드가 서랍 위로 올라가고, 그 카드의 화면 위치에서 HTML 폴더가 커지며 화면 가운데로 날아와 살짝 기울어져 놓인다. 3D 카드는 폴더가 나타나는 순간 숨긴다. 닫을 때는 반대로 폴더가 카드 위치로 줄어들며 사라지고, 3D 카드가 다시 나타나 서랍으로 내려간다.
- **화면 겹침 순서**: 3D 서랍 < 폴더 미리보기 < 전체 보기 그리드 < 상세 페이지. ESC는 맨 위 화면부터 하나씩 닫는다.
- **스크롤 잠금**: 폴더·그리드·상세가 열려 있는 동안 배경 스크롤을 잠근다(WORK에서 벗어나지 않게).
- **"전체 보기" 버튼**: 서랍이 열려 있을 때 "서랍 닫기" 옆에 둔다. 키보드용 숨김 목록에도 넣는다.

**공간**
- 벽: 따뜻한 아이보리. 뒷벽(모니터 뒤)은 비워 둔다 — 지금 뒷벽에 있는 창문을 없앤다.
- 창문: **왼쪽 측면 벽**을 새로 세우고 큰 창(얇은 창틀, 가로·세로 살)을 낸다. 벽과 창틀은 실제로 그림자를 만들어서, 창으로 들어온 햇살이 책상과 바닥에 창틀 모양으로 길게 떨어진다. 창밖은 밝은 빛 면으로 부드럽게 날린다.
- 바닥: 밝은 오크 마루(외부 이미지 없이 코드로 그린 나뭇결 텍스처).

**가구**
- 책상: 우드 상판(옅은 나뭇결) + 얇은 실버 파이프 다리와 가로대(4번째 레퍼런스 같은 구조). 위치는 지금처럼 중앙.
- 의자: 블랙 좌판·등판 + 크롬 기둥·5발 받침. 책상에서 빠져 비스듬히 돌아간 상태.
- 서랍장: 지금 디자인(크롬 레일·아치 받침·라벨 프레임·컵 손잡이)을 유지하고 도장만 **실버(브러시드 알루미늄)/차콜(분체 도장)** 두 가지로. 개발용 패널에 실버/차콜 전환 버튼을 둔다.
- 스탠드: 관절형 실버 스탠드(받침·두 마디 팔·금속 갓), 책상 왼쪽 뒤. ABOUT에서 모니터를 가리지 않는 방향.

**책상 위 소품(최소)**
- 모니터(얇은 베젤, 실버 받침), 키보드, 마우스, 명함, 전화기(오른쪽 — CONTACT 35도 장면용, 지금 자리 유지).
- 작업 흔적: 펼친 노트 + 펜(키보드 왼쪽 앞), 머그컵 하나(왼쪽 뒤, 스탠드 근처).
- 주인공(모니터·서랍장·전화기) 주변은 비워 둔다.

**빛(낮)**
- 햇살: 왼쪽 창밖 낮은 각도의 따뜻한 직사광 1개만 그림자를 만든다.
- 환경광: 부드러운 하늘빛 + 실내 반사광. 대비가 세지 않게.
- 금속 반사: 창 모양 밝은 면을 넣은 환경맵(한 번만 렌더)으로 서랍장·의자 프레임·스탠드에 은은한 반사.
- **조명 설정은 `src/v2/config/lighting.ts` 한 파일에 `day` 프리셋으로 모은다**(햇살 색·세기·방향, 환경광, 환경맵 세기, 노출, 배경색, 창밖 밝기). 밤 버전은 같은 형태의 `night` 프리셋만 추가하면 되게.

**성능**
- 그림자를 만드는 것: 측면 벽·창틀, 책상, 의자, 서랍장, 스탠드, 모니터, 전화기. 받는 것: 바닥, 책상 상판, 벽. 작은 소품은 그림자 생략.
- 그림자 맵은 데스크톱 2048 / 모바일 1024, 해상도 배율(dpr) 상한 1.75.

**확인 방법(스크린샷 4장)**
- 주소 뒤에 `?scene=home|about|work|contact`를 붙이면 그 장면으로 바로 가고, `&cabinet=silver|charcoal`로 서랍장 색을 고른다. 브라우저에서 4개 주소를 열어 캡처하면 된다.

## 이스터에그: 숨은 열쇠와 잠긴 서랍 ✅ 완료 (2026-11-03)

> 우선순위상 3차(이스터에그·원단 스와치) 범위지만 요청에 따라 먼저 임시로 만들었다. 내용물은 모두 자리표시다.

### 동작

- **열쇠**: 머그컵 밑에 작은 황동 열쇠가 깔려 있고 고리만 삐죽 나와 있다(ABOUT·CONTACT 장면에서 보임). 평소엔 몇 초마다 아주 살짝 반짝이고, 마우스를 올리면 반짝임이 커지며 반짝이 입자가 뜬다. 클릭하면 떠올라 돌며 사라지고 열쇠를 얻는다.
- **열쇠 아이콘**: 열쇠를 얻으면 화면 왼쪽 아래에 작은 열쇠 아이콘이 뜬다. 화면 위쪽에 "열쇠를 찾았어요…" 안내가 잠깐 뜬다.
- **잠긴 서랍(가운데·아래)**: 열쇠가 없으면 덜컥 흔들리고 "잠겨 있어요. 어딘가에 열쇠가 있을지도…" 안내가 뜬다. 열쇠가 있으면 열리고, 카메라가 그 서랍 높이로 내려가 안을 내려다본다.
  - 가운데 서랍: 원단 스와치 6장(핑킹 가장자리, 이름표 SWATCH 01~06, 패턴은 코드로 그린 임시 무늬)
  - 아래 서랍: "아직 만드는 중 / 준비되면 이 서랍에 채워 둘게요" 카드 + 빈 봉투
- **유지**: 열쇠와 연 서랍은 브라우저(localStorage `vin-v2-easter-egg`)에 저장된다. 다시 와도 열쇠 아이콘이 있고, 한 번 연 서랍은 잠기지 않으며 닫혀 있을 때도 **살짝 열린 채**(`DRAWER_MOTION.ajar`)로 있어 안이 조금 보인다. 저장이 막힌 환경에서는 그 방문 동안만 유지된다.
- **핵심 정보와 무관**: ABOUT·WORK(맨 위 서랍·전체 보기·상세)·CONTACT는 열쇠 없이도 모두 볼 수 있다. "전체 보기" 버튼은 WORK 서랍이 열렸을 때만 보인다.

## CONTACT 장면: 전화기와 부재중 메시지 ✅ 구현 완료 (2026-11-03) — EmailJS 키 설정 대기

> 콘셉트: 디자이너가 자리를 비운 사이 전화가 울리고, 방문자가 대신 받아 "부재중 메시지"를 남긴다.

### 흐름

1. **울림**: CONTACT에 도착하면 전화기가 따르릉 짧게 흔들리기를 3번 반복하고(약 6초), 본체 앞 작은 표시등이 깜빡인다. 울림이 끝나도 표시등은 계속 천천히 깜빡인다. CONTACT를 떠났다 오면 다시 울린다.
2. **벨소리**: 사운드가 켜져 있을 때만. 음원 파일 없이 Web Audio로 짧은 전화벨을 합성한다. 사운드는 기본 꺼짐(브라우저 자동재생 정책 때문에도 꺼짐이 맞다)이고, 상단 메뉴 옆에 작은 사운드 켜기/끄기 버튼을 둔다. 2차의 "사운드"도 이 스위치를 그대로 쓴다.
3. **hover**: 수화기가 살짝 들리고 "전화 받기" 안내가 뜬다(마우스). 키보드·스크린리더용으로 CONTACT 장면 아래쪽에 "전화 받기" 버튼도 둔다.
4. **받기**: 클릭/탭하면 수화기가 들려 올라가 화면 오른쪽(모바일은 화면 위쪽)으로 부드럽게 이동한다. 위치는 카메라 기준으로 계산해 화면 비율이 달라도 같은 자리에 온다. 본체와 수화기를 잇는 **코일 코드**는 나선 곡선으로 만들어 매 프레임 늘어난 길이에 맞춰 다시 그린다. 동시에 화면 왼쪽(모바일은 아래에서 올라오는 시트)에 메시지 카드가 나타나고 울림·벨은 멈춘다.
5. **닫기**: 카드 밖 클릭, ESC, 닫기 버튼 → 카드가 사라지고 수화기가 제자리로 내려앉는다.
6. **전송**: 성공하면 카드에 "메시지를 남겼어요. VIN이 돌아오면 확인할게요."를 잠깐 보여 준 뒤 카드가 닫히며 수화기를 내려놓는다. 실패하면 입력은 그대로 두고 "전송에 실패했어요. 다시 시도해주세요." + 재시도 버튼.

### 메시지 카드

- 제목 "부재중 메시지 남기기", 안내 "VIN은 잠시 자리를 비웠어요. 메시지를 남겨주시면 돌아와서 연락드릴게요."
- 입력: 이름, 이메일, 메시지 — 모두 필수, 이메일 형식 확인. 오류는 각 칸 아래에 문장으로 표시(`aria-invalid`, `aria-describedby`).
- Send 버튼: 전송 중 로딩 표시 + 비활성(중복 클릭 방지).
- 카드 아래: 이메일 주소 복사 버튼, "메일 앱으로 직접 보내기"(mailto) 링크.
- 디자인: 전화 메모 용지 느낌 — 웜화이트 종이, 옅은 줄, 위쪽 절취선, "WHILE YOU WERE OUT" 같은 작은 머리글, 실버 클립. 강조색(Send 버튼·포커스·체크)은 포인트 색.
- 스팸 방지: 사람 눈에 안 보이는 빈 칸(허니팟) 하나 + 한 번 보낸 뒤 잠깐 재전송 제한.

### 지킬 것

- 카드가 열려 있는 동안 배경 스크롤 잠금 → 카메라가 움직이지 않는다. 카드 안 스크롤은 카드만.
- 키보드: 카드가 열리면 이름 칸으로 포커스, Tab 순서대로 이동, 입력칸에서 Enter = 전송(메시지 칸은 Enter가 줄바꿈이라 Ctrl/⌘+Enter = 전송), 닫으면 포커스를 "전화 받기"로 돌려준다.
- 움직임 줄이기: 흔들림 없이 표시등만 깜빡이고, 수화기는 날아가지 않고 바로 옆으로 놓인다. 카드는 페이드만.

### 전송(EmailJS)

- 키가 비어 있으면 Send 대신 "메일 앱으로 보내기"를 안내한다(사이트가 깨지지 않게).
- 템플릿 변수: `from_name`, `reply_to`, `message`, `sent_at`, `page_url`.

### EmailJS 설정 순서(직접 할 일)

1. https://www.emailjs.com 에서 가입(무료 플랜: 한 달 200통).
2. **Email Services → Add New Service → Gmail** → 받을 Gmail로 로그인·연결 → 만들어진 **Service ID**(예: `service_xxxxxxx`)를 적어 둔다.
3. **Email Templates → Create New Template**
   - Subject: `[VIN 포트폴리오] {{from_name}}님의 부재중 메시지`
   - Content:
     ```
     {{from_name}} ({{reply_to}}) 님이 메시지를 남겼어요.

     {{message}}

     — 보낸 시각: {{sent_at}}
     — 보낸 페이지: {{page_url}}
     ```
   - To Email: 받을 주소(예: socutesubin@gmail.com), **Reply To: `{{reply_to}}`** (메일 앱에서 "답장"을 누르면 보낸 사람에게 바로 간다)
   - 저장 → **Template ID**(예: `template_xxxxxxx`)를 적어 둔다.
4. **Account → General → Public Key**를 적어 둔다.
5. (권장) **Account → Security**에서 허용 도메인에 Vercel 주소와 `localhost`를 넣는다(다른 사이트가 키를 가져다 쓰지 못하게).
6. 프로젝트 폴더에서 `.env.example`을 복사해 `.env.local`을 만들고 세 값을 채운다. `.env.local`은 GitHub에 올라가지 않는다.
   ```
   VITE_EMAILJS_SERVICE_ID=service_xxxxxxx
   VITE_EMAILJS_TEMPLATE_ID=template_xxxxxxx
   VITE_EMAILJS_PUBLIC_KEY=xxxxxxxxxxxxxxx
   ```
7. 개발 서버를 껐다 켠다(`npm run dev`). 환경 변수는 서버를 켤 때만 읽는다. CONTACT에서 직접 보내 보고 메일함을 확인한다.

### Vercel에 키 넣기

1. Vercel → 프로젝트(vin-portfolio) → **Settings → Environment Variables**.
2. 위 세 이름과 값을 그대로 추가한다. Environment는 **Production·Preview** 둘 다 체크(v2 미리보기 주소에서도 쓰려면 Preview 필수).
3. **Deployments**에서 최신 배포의 ⋯ → **Redeploy**(값을 넣은 뒤 다시 빌드해야 반영된다).

## 기준 비주얼: 레트로 사물 + 밝은 작업실 ✅ 적용 (2026-11-03)

> 첨부한 HOME 시안(베이지 CRT 컴퓨터, 산업용 책상, 나비 포스터가 있는 방)을 앞으로 모든 장면의 기준 비주얼로 삼는다.
> 방향: **"레트로한 사물이 놓인, 밝고 정돈된 현대적인 작업실"** — 사물은 레트로, 벽·빛·구도는 밝고 깨끗하게.

### 지킬 것

- 4개 장면 카메라·스크롤, 이미 만든 기능(서랍 열기·카드·폴더·그리드·전화기·이스터에그 열쇠와 잠긴 서랍) 유지.
- 사물 위치를 바꾸면 기능이 깨지지 않는지 확인하고, 바꾼 위치·카메라 값을 기록.
- 오브젝트별 컴포넌트 구조 유지(GLB 교체 가능).

### 계획

**공간**
- 벽: 밝은 웜화이트, 깨끗하게. 아래에 흰 걸레받이(뒷벽·측면 벽).
- 창: 왼쪽 벽 흰 창틀. 창밖은 빛 면 대신 코드로 그린 **벽돌 벽 + 초록 나무** 그림(살짝 흐리고 밝게). 창턱에 화분 하나.
- 바닥: 지금보다 밝은 우드.
- 뒷벽 오른쪽: 큰 종이 달력(현재 달 이름 + 날짜 그리드, 오늘 날짜 표시). 그 외 벽 장식 없음.

**가구**
- 책상: 회색 철제 상판(살짝 둥근 모서리) + 철제 다리·가로대.
- 서랍장: **올리브 그레이 도장 철제** — 모양(크롬 레일·아치 받침)은 유지하고, 컵 손잡이 대신 **가로형 크롬 바 손잡이**, 서랍마다 **작은 열쇠 구멍**(가운데·아래는 잠긴 서랍, 맨 위에도 하나). 맨 위 "WORK" 라벨 홀더는 남긴다(손잡이 위 작은 라벨). 색은 `cabinet.ts` 한 곳에서. 개발용 패널의 실버/차콜 버튼은 없앤다.
- 의자: 크롬 프레임 + **다크 브라운 가죽** 좌판·등받이, 비스듬히 돌아간 채(지금 위치 유지).

**책상 위**
- 노란 관절형 스탠드(왼쪽 뒤, 갓은 머스터드 옐로우 광택).
- **플립 시계**(스탠드 옆): 실제 현재 시각(시:분)을 표시하고 1분마다 갱신.
- **레트로 컴퓨터**(가운데): 베이지 CRT 모니터 + 본체 + 베이지 키보드 + 마우스. HOME 등에서는 화면이 꺼진 어두운 유리, **ABOUT에 오면 화면이 켜진다**(부드럽게 밝아지는 부팅 화면 — 지금은 "VIN / ABOUT" 자리표시, 실제 소개 내용은 ABOUT 단계에서).
- 펼친 노트 + 펜(모니터 왼쪽 앞, 지금 위치).
- 펜꽂이(연필 몇 자루 + 가위): 모니터 오른쪽 뒤.
- **빨간 다이얼 전화기**(오른쪽, 지금 위치) — 본체·수화기 빨강, 꼬인 코드도 빨강 계열.
- 머그컵: 위치 그대로(밑에 이스터에그 열쇠).

**색**
- 바탕: 웜화이트, 우드, 회색 철재, 올리브 그레이. 포인트는 **노랑(스탠드)·빨강(전화기)** 둘만. 코발트블루는 서랍 안 폴더에만.
- 사이트 UI 포인트 색(`--accent`, Send 버튼 등)도 코발트 대신 공간 포인트에 맞춘다 — 확인 필요(아래).

**빛(낮)** — `config/lighting.ts`의 `day`만 고친다
- 왼쪽 창에서 낮은 각도로 들어오는 따뜻하고 선명한 햇살(그림자 가장자리 더 또렷하게).
- 창틀 그림자가 **벽과 바닥에 대각선으로 길게** — 지난번엔 모니터 뒤를 비우려고 햇살을 앞쪽으로 돌렸지만, 이번엔 시안처럼 **뒷벽 왼쪽(모니터 왼편)**에 창 모양 빛이 떨어지게 방향을 다시 잡는다. 모니터 바로 뒤는 피한다.
- 전체적으로 밝고 깨끗하게: 노출·환경광을 올리고 색온도는 누렇지 않게(햇살만 따뜻하게).

**성능**

**바뀐 것**
- 공간: 흰 걸레받이, 흰 창틀 + 창턱 화분, 창밖에 코드로 그린 벽돌 벽과 초록 나무, 밝은 우드 바닥, 뒷벽 오른쪽 큰 종이 달력(이번 달, 오늘 날짜 동그라미).
- 가구: 회색 철제 책상(각관 다리·프레임), 올리브 그레이 서랍장(가로형 크롬 바 손잡이, 서랍마다 열쇠 구멍), 다크 브라운 가죽 의자.
- 책상 위: 노란 관절형 스탠드, 플립 시계(실제 현재 시각, 1분마다 갱신), 레트로 컴퓨터(베이지 CRT + 본체 + 키보드 + 마우스, **ABOUT에서만 화면이 켜짐** — "VIN / ABOUT" 자리표시), 펜꽂이(연필·가위), 빨간 다이얼 전화기와 빨간 꼬인 코드(표시등은 빨간 본체에서 보이게 따뜻한 흰빛). 노트·머그(밑에 열쇠)는 그대로.
- 빛(`config/lighting.ts` `day`): 햇살을 뒷벽 쪽으로 돌려 창 모양 빛과 창틀 그림자가 **뒷벽 왼쪽과 창가 바닥에 대각선으로** 떨어지게 했다(모니터 바로 뒤는 비움). 그림자 가장자리를 더 또렷하게, 전체 노출·환경광을 올리고 누런 톤을 뺐다.
- 그림자: 벽·창틀·창턱, 책상, 서랍장, 의자, 컴퓨터, 스탠드, 전화기만. 키보드·마우스·시계·펜꽂이·달력·화분은 그림자를 만들지 않는다.
- 개발용 패널의 실버/차콜 버튼과 `?cabinet=` 주소 옵션은 없앴다.

**위치·카메라**
- 카메라 값은 바꾸지 않았다(4개 장면 모두 구도 유지).
- 위치: `monitor` → `computer` [-0.1, 0.75, -0.6](화면 가운데 높이 약 1.04m로 ABOUT 시점과 맞음). 새로 추가: `clock` [-0.47, 0.75, -0.75], `penHolder` [0.25, 0.75, -0.72], `plant`(창턱), `calendar` [1.05, 1.52, 뒷벽]. 머그·열쇠·전화기·서랍장·의자 위치는 그대로.
- 기능 확인: WORK 서랍 열기 → 카드 → 폴더 → 상세 → 그리드 → 돌아오기, 잠긴 서랍 덜컥, 열쇠 줍기 → 가운데 서랍 열기, CONTACT 전화 받기 → 카드. 모두 정상.
