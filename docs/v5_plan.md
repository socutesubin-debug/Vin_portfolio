# Vision INside · 인터랙티브 포트폴리오 기획 v5

## 1. 전체 화면 흐름

**Home 책상 → Work 수납장 → Projects 목록 → 프로젝트 상세 → Contact 전화기 → 메시지 작성**

- Home의 서류더미를 선택하면 자기소개서를 연다. 노트북을 선택하면 이력서를 연다.
- Work에서 가운데 서랍을 열고 파일을 선택하면 Projects 목록으로 이동한다.
- 프로젝트 카드를 누르면 상세가 열린다. 상세 하단의 ‘연락하기’ 버튼은 Contact로 연결한다.
- Contact에서 전화를 받으면 수화기와 메시지 작성란이 나타난다.

공통 메뉴는 `HOME / ABOUT / WORK / CONTACT`로 구성한다. ABOUT은 Home의 자기소개서를 여는 바로가기로 연결한다. 프로젝트 목록과 연락 양식에는 장면을 거치지 않고 도착할 수 있는 텍스트 링크를 제공한다. 프로젝트 상세에서 목록으로 돌아올 때는 필터와 스크롤 위치를 복원한다.

## 2. 화면과 사물별 인터랙션

### Home · 책상 위에서 나를 소개한다

**레퍼런스 1–2.** 1번의 선명한 질감과 사물 배치, 2번의 따뜻한 조명을 참고한다. 사물이 없는 고화질 책상 배경 위에 노트북, 서류더미, 조명 스탠드, 커피, 만년필을 각각 3D로 배치한다. 사진과 사물의 원근, 광원 방향, 접촉 그림자를 맞춘다. 모바일 세로 구도에서는 서류더미와 노트북을 앞쪽에 배치한다.

| 사물 | 클릭·탭 후 반응 | 도착 상태 |
|---|---|---|
| 서류더미 | 맨 위 종이가 앞으로 밀리고 종이 스치는 소리가 난다 | HTML 자기소개서 패널 |
| 노트북 | 덮개가 힌지를 중심으로 열리고 노트북 전체가 화면 중앙으로 이동한다 | 노트북 화면에 이력서 표시. 모바일은 전체 폭 패널 |
| 조명 스탠드 | 스위치 소리와 함께 책상 위 조명 범위가 밝아지거나 어두워진다 | 조명 상태 전환 |
| 커피 | 잔이 살짝 움직이고 책상에 닿는 소리가 난다 | 짧게 반응한 뒤 제자리 |
| 만년필 | 펜이 살짝 굴러가고 가볍게 탁 소리가 난다 | 짧게 반응한 뒤 제자리 |

서류와 노트북에는 ‘자기소개서 보기’, ‘이력서 보기’ 라벨을 붙인다. 패널을 닫으면 책상으로 돌아가고 키보드 포커스는 열었던 버튼으로 돌아간다.

### Work · 서랍을 열어 프로젝트를 찾는다

**레퍼런스 3–5.** 화면을 채운 철제 수납장 중 가운데 서랍에 ‘프로젝트 서랍 열기’ 라벨을 붙인다. 클릭하면 서랍이 앞으로 미끄러지고 안쪽에 정리된 파일 탭이 보인다. 주변 수납장은 배경, 가운데 서랍과 파일은 움직이는 요소로 분리한다.

파일 탭을 누르면 파일이 앞으로 살짝 빠져나온 뒤 **7번 Projects 목록**으로 전환한다. 탭에 실제 작업 분야를 붙인 경우 해당 필터가 적용된 목록을 연다. 탭의 분류는 수록 작업을 확인한 뒤 정한다.

### Projects · 썸네일에서 케이스 스터디까지

**레퍼런스 7.** 큰 썸네일과 제목, 화살표를 사용한다. 데스크톱 2열, 모바일 1열로 배치한다. 카드에 프로젝트명과 한 줄 요약을 표시하고 UX/UI 직무에 가장 잘 맞는 작업을 앞에 둔다. 필터와 건수는 실제 프로젝트 데이터를 반영한다.

상세 흐름은 **배경·기간·팀·내 역할 → 문제와 목표 → 조사와 관찰 → 디자인 판단 → 흐름과 주요 화면 → 피드백과 수정 → 결과와 배운 점**이다. 개인 작업, 수업 과제, 가상 프로젝트의 성격과 기여 범위를 밝히고 조사나 성과는 확인된 내용만 기록한다. 하단에 ‘프로젝트 목록’과 ‘연락하기’를 둔다.

### Contact · 전화를 받으면 메시지를 남길 수 있다

**레퍼런스 6 → 8.** 벽걸이 전화기가 가볍게 흔들리고 ‘전화 받기’가 보인다. 소리를 켠 방문자에게 짧은 벨소리를 재생한다. 전화 받기를 누르면 벨이 멈추고 수화기가 왼쪽에 자리하며 오른쪽에 작성란이 열린다. 모바일은 수화기 아래에 양식을 배치한다.

안내 문구는 “잠시 자리를 비웠어요. 메시지를 남겨주시면 이메일로 답장드릴게요.”로 한다. 이름·소속(선택), 회신 이메일(필수), 메시지(필수)를 받으며 ‘메시지 바로 남기기’를 제공한다. 전송 중에는 중복 제출을 막고 서버가 접수하면 완료 상태를 표시한다. 실패 시 입력을 유지해 재시도할 수 있게 한다. 수신 주소와 공개할 연락처는 제작 전에 확인한다.

## 3. 전환과 사운드 규칙

| 구간 | 모션 | 프로토타입 초기 시간 |
|---|---|---|
| Home ↔ Work ↔ Contact | 현재 장면과 다음 장면을 페이드로 연결 | 300–400ms |
| 노트북 → 이력서 | 힌지 회전과 중앙 이동을 겹쳐 재생한 뒤 이력서 표시 | 700–900ms |
| 서랍 닫힘 → 열림 | 서랍이 앞으로 미끄러지며 파일 탭 노출 | 450–600ms |
| 파일 → Projects | 파일이 앞으로 나오고 목록으로 전환 | 350–500ms |
| 전화 받기 → 작성 | 벨 정지 후 수화기 이동과 패널 등장 | 500–700ms |

연속 클릭과 뒤로가기에서도 장면과 실제 페이지를 일치시킨다. 새 페이지에 도착하면 제목으로 포커스를 옮긴다. 첫 방문은 음소거로 시작하고 사용자가 ‘소리 켜기’를 누르면 페이지 이동 간 설정을 유지한다. 전화 받기나 화면 이탈 시 벨소리를 멈춘다. 소리를 끈 상태에서도 라벨로 상태와 행동을 알려준다. 모션 줄이기를 켠 경우에는 큰 이동과 반복 흔들림을 생략하고 바로 다음 상태를 표시한다.

[브라우저 자동 재생 정책](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay) · [모션 줄이기 설정](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40media/prefers-reduced-motion)

## 4. 제작 도구와 용어

**직접 코딩하는 경우의 1차 조합은 Blender → GLB → Three.js + GSAP Core + HTML/CSS다. Spline은 초기 동작 검증에 사용한다.**

| 도구 | 역할과 적용 |
|---|---|
| Blender | 노트북 본체·덮개, 수납장·서랍, 전화기·수화기를 분리해 모델링하고 GLB로 내보낸다. 덮개 피벗은 힌지에 둔다 |
| Three.js | `GLTFLoader`로 GLB를 읽고 `Raycaster`로 클릭한 사물을 찾는다. 사진과 맞는 카메라, 사물 배치, 조명을 설정한다 |
| GSAP Core | `timeline()`으로 힌지 회전, 중앙 이동, 콘텐츠 등장 같은 동작의 순서와 겹침을 제어한다. 서랍, 수화기, 페이지 페이드에도 적용한다 |
| Spline | 노트북이 열리는 각도나 서랍이 나오는 거리를 빠르게 시험한다. Spline 장면을 그대로 웹에서 재생하는 경우에는 Spline Runtime을 별도 경로로 검토한다 |
| HTML/CSS + HTML Audio | 이력서, 프로젝트, 버튼과 양식을 HTML로 제공하고 짧은 효과음을 재생한다. 메시지 접수는 별도 서버 경로에 연결한다 |

Spline 내보내기 방식마다 이벤트와 애니메이션 지원 범위가 다르다. 상호작용은 Three.js와 GSAP에서 구현한다. 파일 탭과 프로젝트 카드가 같은 요소처럼 이어지는 연출을 채택하면 GSAP Flip을 검토한다. 1차 범위는 GSAP Core로 구현한다.

[Spline 내보내기](https://docs.spline.design/exporting-your-scene/web/exporting-as-code) · [Three.js GLTFLoader](https://threejs.org/docs/#GLTFLoader) · [Three.js Raycaster](https://threejs.org/docs/#Raycaster) · [GSAP Timeline](https://gsap.com/docs/v3/GSAP/gsap.timeline%28%29/) · [GSAP Flip](https://gsap.com/docs/v3/Plugins/Flip/)

| 용어 | 적용 |
|---|---|
| 합성 장면 · Composite scene | 정적 공간 이미지 위에 움직이는 3D 사물을 겹친 장면 |
| 핫스폿 · Hotspot | 서랍 손잡이나 만년필을 선택할 수 있는 영역. 실제 사물보다 넓게 잡을 수 있다 |
| 어포던스와 시그니파이어 | 손잡이가 당기는 행동을 암시하고 ‘프로젝트 서랍 열기’ 라벨이 실제 행동을 알려준다 |
| 마이크로인터랙션 | 컵이 살짝 움직이거나 스탠드가 켜지는 짧은 반응 |
| 피벗 · Pivot | 사물이 회전하는 기준점. 노트북은 힌지에서 회전한다 |
| 이징 · Easing | 모션의 속도 변화. 서랍이 움직이다가 끝에서 부드럽게 멈춘다 |
| 페이지 전환과 상태 전환 | Work에서 Contact로 이동하는 것은 페이지 전환이다. Contact에서 전화 받기는 상태 전환이다 |
| 폴백 · Fallback | 3D가 늦게 로드되거나 실행되지 않을 때 정적 이미지와 링크로 콘텐츠를 제공하는 방식 |

## 5. 제작 순서와 확인 항목

1. **동선 검증** — 정적 화면으로 자기소개서, 이력서, 프로젝트 상세, 연락 양식까지 연결한다.
2. **대표 장면 검증** — 노트북 하나로 배경과 3D의 원근과 빛을 맞추고 모바일 이력서 가독성을 확인한다.
3. **장면 확장** — 서랍과 파일, 수화기를 연결한 뒤 작은 소품과 효과음을 붙인다. 모델은 해당 장면이 필요할 때 불러온다.
4. **최종 확인** — 터치, 키보드, 무음, 모션 줄이기, 느린 로딩에서도 핵심 콘텐츠를 열 수 있는지 확인한다. 뒤로가기로 목록 위치가 복원되고 전송 실패 후 재시도할 수 있어야 한다.

**제작 전 확인할 항목**

- 수록 프로젝트, 실제 역할·기간·근거 자료, 파일 탭 분류
- 자기소개서 원고와 공개용 이력서
- 공개 연락처와 실제 메시지 수신 주소
- 책상·수납장·전화기 이미지와 효과음의 제작 또는 사용 출처
- ABOUT 연결, 소품별 반응, 전환 시간은 프로토타입에서 검증할 초안
