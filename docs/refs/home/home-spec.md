# VIN Home 책상 — 구현 명세 (home-prototype.html 이 기준)

값이 이 문서와 시험판 코드가 다르면 **시험판 코드가 맞다.** 단위는 cm, 윗면 높이 TOP = 75.
목표 화면: home-target.png (1280×800). 시험판: prototype/home-prototype.html (같은 폴더의 models.js 필요, 브라우저로 열면 동작).

## 1. 구조
- 3D는 이 책상 한 장면만. About·Work·Contact는 같은 장면에서 카메라가 물건으로 다가가고 그 위에 HTML이 뜨는 방식.
- 해시: #home  #about(명함)  #screen(모니터)  #work(서랍)  #contact(전화기). Back to desk / Esc / 뒤로가기로 복귀.
- 이동은 1초 안쪽의 부드러운 이징 하나(lerp .06). prefers-reduced-motion 이면 즉시 이동. 과한 연출 금지.
- 글자·목록·폼은 전부 HTML. 색은 theme 한 곳에서만 관리 (진한 색 / 연한 색 두 개).

## 4. 빛
- 햇빛: DirectionalLight 세기 3, 위치 (-300,250,260), 그림자 on (맵 2048, 범위 ±150, bias -.0005, radius 2).
- 주변광: HemisphereLight(흰, 회색, 1.15).
- 스탠드 스포트: 세기 2200(켰을 때), 각도 .55, 거리 120. 빛 원뿔은 흰색 additive, 불투명도 .4.
- 창 블라인드 그림자: 보이지 않는 막대 7개 (박스 2×3.2×150, x=-150, y=85+i*18, z=20, colorWrite false, castShadow).

## 5. 듀오톤 스타일 (duotoneStyle.ts 에 반영됨)
- 팔레트: 진한 색 #1f4bd0, 연한 색 #e9e4d8. 배경(scene.background)은 검정 → 진한 색이 됨. 바닥은 없음.
- 밝기: smoothstep(.12, .78) → 5단계 끊기. renderer.outputColorSpace Linear, NoToneMapping.
- 외곽선: 법선 + 깊이 4방향, 간격 2px, 법선 차이 기준 0.62(슬라이더 기본 55%), 깊이 기준 .04·거리, 세기 ×.4 최대 .8.
- 종이 질감: **정적(깜빡임 없음)**, 칸 2.5px 진폭 .09×gAmt + 칸 9px 진폭 .05×gAmt, gAmt 기본 .35.
- 외곽선 계산에서 빼는 것(fx): 빛 원뿔, 모니터 검은 평면, 글자 스티커, 블라인드 막대 → 법선 패스에서 잠시 숨김.
- 화면에 슬라이더 2개(질감 / 외곽선) + 팔레트 버튼 4개(코발트·올리브·버건디·차콜). 배포 땐 ?tune 일 때만 보이게.
