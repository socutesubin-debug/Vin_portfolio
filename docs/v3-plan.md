## 1. 콘셉트 — 가장 먼저 이해해야 할 이야기

**잠시 자리를 비운 디자이너의 작업실 (A Designer's Workspace)**

디자이너가 작업하는 모습을 관찰하며 시작한다. 방문자의 스크롤에 맞춰 카메라가 모니터 반대편에서 사선으로 회전하고, PARK SU VIN → VISION INSIDE → VIN 타이포가 나타난다. 디자이너가 의자를 돌리고 잠시 자리를 비우면 카메라는 책상 위로 접근한다. 이제 방문자가 공간을 탐험하며 디자이너의 사고, 이력, 프로젝트, 연락 수단을 직접 발견한다. 전화기에서 연락을 주고받는 기능적 CONTACT 뒤에는 카메라가 다시 물러나 작업실 전체를 조망하고 VIN 로고와 Explore to Evolve로 마무리하는 별도의 ENDING이 이어진다. 처음에는 낯설었던 공간이 탐험 후에는 디자이너를 이해한 장소로 바뀌는 순환형 내러티브다.

- **핵심 메시지:** 아이디어를 제안에서 끝내지 않고 경험으로 구현하는 디자이너.
- **경험 원칙:** Scroll = 공간·이야기의 진행 / Click·Drag = 사물의 발견과 조작 / HTML UI = 정보 열람·다운로드·연락.

## 2. 차별화 포인트

1. **관찰에서 탐험으로 자연스럽게 전환:** 인물이 퇴장하는 행동이 사용자 인터랙션의 시작을 설명한다.
2. **실제 작업실을 정보구조로 활용:** 모니터=ABOUT, 책상 위 사물=개인 브랜딩, 서랍=WORK, 전화기=CONTACT. 메뉴를 공간적 메타포와 연결한다.
3. **고품질 3D와 읽기 쉬운 콘텐츠의 분리:** 3D 공간의 존재감은 유지하면서, 문서·그리드·연락 폼은 웹 표준 UI로 구성한다.
4. **발견형 인터랙션:** 명함과 열쇠를 360도 회전해 확인하고 조명을 켜고 끈다. 선택적 잠금 서랍 이스터에그가 재탐색의 동기가 된다.
5. **프로젝트 탐색의 2단계 구조:** 실제 서랍 속 폴더 → 배경 블러 위의 Selected Projects 2열 그리드(필터) → 대형 가로 카드·다음 카드 일부 노출의 상세 탐색.
6. **시각적 완성도와 실행 가능성의 균형:** 정적 장면은 베이크드 라이팅, 동적 사물은 개별 애니메이션과 적절한 실시간 효과로 처리한다.
7. **시작과 끝의 장면을 연결:** 관찰자로 시작한 방문자가 공간을 탐험한 뒤 다시 전체 작업실을 보는 동안 같은 공간의 의미가 달라진다. CONTACT는 기능적 마무리, ENDING은 브랜드 경험의 감성적 마무리를 담당한다.

### 2-1. 빈티지 작업실의 의미 — "아날로그 공간에서 디지털 경험으로"

> 아이디어가 태어나는 아날로그 작업실에서, 작동하는 디지털 경험으로.

- **디자인 과정을 공간으로:** 노트·서류철·다이얼 전화기 같은 아날로그 사물은 아이디어의 시작을, 그 안에서 펼쳐지는 현대적인 인터페이스는 아이디어가 경험으로 구현된 결과를 뜻한다. 낡은 서랍을 열면 현대적인 프로젝트 화면이 펼쳐지는 순간이 "아이디어 → 경험" 과정 자체다.
- **기능이 읽히는 사물 = 어포던스:** CRT 모니터=화면 너머를 들여다보는 창(Vision Inside, ABOUT), 철제 서류 캐비닛=쌓아온 작업 아카이브(WORK), 다이얼 전화기=직접 연결되는 대화(CONTACT), 열쇠와 잠긴 서랍=아직 열리지 않은 가능성(이스터에그).
- **기억에 남는 차별화:** 어둡고 미니멀한 일반적인 UX 포트폴리오와 달리, 따뜻한 빛이 드는 작업실은 한 번 보면 기억에 남는다.
- **사람이 느껴지는 포트폴리오:** "이 사람이 실제로 일하는 공간"이라는 온기.
- **만드는 사람의 정체성:** 패션 디자이너로 실물·소재를 손으로 다루던 경험이 공간에 묻어난다(원단 스와치 이스터에그와 연결).
- **오해를 막는 장치 (구현 원칙):** 공간은 따뜻하고 아날로그하게, 화면 위 UI(이력서·프로젝트 그리드·메일 카드)는 현대적인 웹 표준으로.

## 3. 확정된 방향 및 미정 사항

| 영역 | 현재 결정 |
| --- | --- |
| 브랜드 | VIN — Vision Inside |
| 전체 흐름 | INTRO → HOME / 모니터 ABOUT → WORK → CONTACT → ENDING |
| 공간 | 빈티지 작업실: 창 왼쪽, 노란 스탠드, 베이지 레트로 모니터, **버건디 의자(확정)**, 회색 철제 책상, **올리브 그레이 서랍장(확정)**, 빨간 다이얼 전화기 |
| 색 | 바탕: 웜화이트·우드·회색 철재·올리브 그레이. 포인트: 노랑(스탠드)·빨강(전화기). **코발트블루는 서랍 안 폴더에만** |
| INTRO 제작 | **확정:** S01–S03은 영상(스크롤 재생), S04부터 baked 3D. 3D HOME 카메라 구도 캡처를 영상의 끝 프레임으로 사용 |
| 사운드 | **확정:** 좌측 하단 사운드 설정 버튼(켜기/끄기) |
| 카메라 | INTRO 오비트 → HOME 사선 구도 → Dolly In → 서랍으로 하강 → 전화기로 이동 → 작업실 전체로 Pull Back |
| 조명 | 부드러운 오후 자연광, 자연스러운 창틀 그림자, 과도한 오렌지 보정 금지 |
| 3D 제작 | 모델 자체는 별도 제작·확보. **Blender에서는 모델링하지 않고 Lightmap Baking만 수행** |
| ABOUT | 모니터 내부 이력서·자기소개서 읽기 및 다운로드. **스크롤(모니터 앞에서 멈추고 화면이 켜짐)과 클릭 모두로 진입(확정)** |
| WORK | 첫 서랍은 **스크롤하면 자동으로 열리고, 클릭해도 열림(확정)**. 폴더형 아카이브, 그리드·상세 캐러셀, **필요한 프로젝트에만 고유 주소(딥링크)** |
| 이스터에그 | 열쇠를 찾아야 남은 서랍 개방. **내용 미정** (V2의 원단 스와치·"아직 만드는 중" 임시 콘텐츠 유지) |
| CONTACT | 전화벨 → 수화기 확대 → 메모 작성 및 전송 UI. 연락은 선택 행동, 전송 없이도 엔딩 진입 가능 |
| ENDING | 수화기 복귀 → 카메라가 뒤로 물러나 빈 작업실 와이드 → VIN / Vision Inside / Explore to Evolve → Explore Again·Back to Projects |
| 엔딩 연출 | A(다시 비어 있는 작업실) + B(VIN 로고 엔딩) 결합. 세부 전환 타이밍은 검증 예정 |
| 개인 소품 | 스케치북/작업 노트·카메라·디자인 샘플 등 후보, 최종 미정 |
| 실제 에셋·인물 표현·문서·프로젝트 상세자료 | 후속 확정 |

## 5. WORK 프로젝트 콘텐츠 구성 원칙

- **Reference 01** (`docs/v3-refs/work-folder-layout.png`): 하나의 큰 프로젝트 카드가 화면 대부분을 차지하고 다음 카드가 일부 노출되는 가로 탐색. 이전·다음/목록 복귀 제공. → S13
- **Reference 02** (`docs/v3-refs/work-project-grid.png`): Selected Projects 제목, 카테고리 필터(개수 표시), 2열의 큰 썸네일과 간결한 프로젝트명·분야 텍스트. → S12. 원본 스튜디오의 브랜드·프로젝트명·썸네일은 쓰지 않고 레이아웃 구조만 참고.
- 프로젝트 설명의 최소 정보: 개요, 문제·목표, 조사 근거, 본인 역할, 디자인 프로세스, 핵심 화면, 결과, 한계 및 배운 점. **실자료 없이 임의의 성과 수치 작성 금지.**
- 그리드는 3D 내부의 평면 메시가 아니라 반응형 HTML 오버레이로 구현하고, 실제 3D 배경만 흐림.
- 카테고리는 UX/UI·Web·Branding·Editorial 후보이며 최종 미정. 데이터 파일에서 쉽게 바꿀 수 있게 한다.

## 6. 화면 간 상태·복귀 규칙

- **전역 상태:** currentScene, isOverlayOpen, selectedObject, hasKey, selectedCategory, selectedProject, lampOn, soundOn, prefersReducedMotion.
- **오브제 포커스 진입:** 카메라·스크롤 입력 중지, 배경만 블러, 중앙 회전/읽기 콘텐츠 선명하게 유지, Escape·닫기로 원위치.
- **열쇠:** HOME에서 발견 시 hasKey=true. 재방문 시 상태 유지(V2 방식: localStorage).
- **잠긴 서랍:** 열쇠 없어도 WORK 및 CONTACT의 기본 탐색은 가능. 잠금 피드백과 힌트 제공.
- **엔딩 진입:** 연락 폼 사용을 강제하지 않는다. 보내기 성공·닫기·스크롤 모두 엔딩 흐름을 방해하지 않아야 한다.
- **네비게이션:** HOME/ABOUT/WORK/CONTACT 바로가기 및 역스크롤·키보드 진입 경로 제공. ABOUT은 HOME 모니터의 하위 진입.
- **움직임 축소·모바일·터치:** 과도한 3D 카메라 회전을 줄이고 문서·프로젝트를 읽을 수 있는 대체 UI 제공. 호버는 탭으로, 드래그 회전은 터치로.

## 6-1. 첫 진입·건너뛰기·빠른 보기 규칙 (확정)

- **첫 방문:** INTRO 영상부터 시작. 스크롤을 계속 내리면 HOME 탐험(S04)까지 **5–10초** 안에 도착.
- **건너뛰기:** 몰입을 위해 눈에 띄지 않게. INTRO 시작 2–3초 뒤 화면 구석에 작은 텍스트(Skip)로 낮은 대비로 나타나고, 클릭 시 S04로 이동.
- **재방문:** 이미 INTRO를 본 방문자는 HOME 탐험에서 시작하고, "인트로 다시 보기" 작은 버튼 제공.
- **역스크롤:** 3D 구간에서 위로 스크롤해도 INTRO 영상은 되감지 않는다(다시 보기 버튼으로만 재생).
- **ENDING:** Explore Again은 INTRO를 건너뛰고 HOME 탐험(S04)으로, Back to Projects는 WORK 그리드(S12)로 이동.
- **빠른 보기:** 3D 없이 이력서·프로젝트 목록·연락처를 보는 일반 웹 페이지 경로(예: `/quick`). 네비게이션 또는 푸터에 작게.
- **프로젝트 주소:** 지원서에 직접 넣을 프로젝트에만 고유 주소(예: `/work/프로젝트-id`). 주소로 들어오면 INTRO 없이 해당 프로젝트 상세를 바로 연다.
- **사운드:** 좌측 하단 버튼으로 켜고 끈다. 기본값은 꺼짐, 설정은 다음 방문에도 유지.
- **인트로 타이포:** 직무 문구는 당분간 넣지 않는다(PARK SU VIN → VISION INSIDE → VIN).

## 7. 제작 파이프라인과 구현 범위

1. 장면 스토리보드 및 19개 화면 와이어프레임 확정.
2. **INTRO 영상 제작 (S01–S03):** *(재생 시스템은 구현됨 → 13장)* 3D HOME 장면을 먼저 완성 → HOME 카메라 구도 고해상도 캡처 → 이 이미지를 영상의 끝 프레임으로 지정해 제작(정면 관찰 → 사선 오비트 → HOME 구도, 의자 회전·퇴장) → 이미지 시퀀스로 변환해 스크롤 재생 → 마지막 프레임에서 3D로 전환.
3. 3D 모델은 외부 제작 또는 에셋 확보(Hyper3D 등). **Blender 사용 목적은 Lightmap Baking 전용, 모델링 작업은 하지 않는다.**
4. **굽기 전 UV 정리:** AI 생성 모델은 UV가 고르지 않을 수 있으므로, Blender에서 라이트맵용 두 번째 UV를 새로 펼친다(모델링 아님).
5. 정적 메시의 UV·재질·베이크 적합성을 확인하고, Blender에서 간접광·그림자를 Lightmap으로 베이킹한다.
6. 의자·서랍·수화기·열쇠·명함 등 동적 오브제는 정적 그림자를 붙이지 않고 동적 접촉 그림자/광원·애니메이션으로 처리한다.
7. React + Three.js / React Three Fiber 및 GSAP ScrollTrigger로 스크롤 카메라·오브제 인터랙션 구현. 문서·그리드·폼은 HTML/CSS 기반.
8. 성능: 모바일 LOD, GLB 압축(Meshopt), KTX2 등 텍스처 최적화, 프레임레이트와 로딩 성능 검증. 원본 노멀 유지, 과도한 폴리곤 감축 금지.
9. 최종 QA: 접근성, 반응형, 열쇠 상태, PDF 다운로드, 메시지 실제 전송 결과.

## 8. 와이어프레임 표기 규칙

각 장면은 16:9 데스크톱 기준으로 (1) 카메라 구도·피사체, (2) 3D 오브제 클릭 영역, (3) 2D UI 안전영역, (4) 스크롤/클릭/드래그 입력, (5) 진입·종료 상태를 표시한다. 정확한 카메라 좌표·초점거리·시간은 3D 에셋과 화면 설계 검증 후 확정한다. 카메라 값은 `config/scenes.ts`, 사물 위치는 layout 파일에 모아 숫자로 조정 가능하게 한다.

## 9. ENDING 상세 연출 — CONTACT와 분리

**채택한 방향: A(다시 비어 있는 작업실) + B(VIN 로고 엔딩).** C(디자이너가 돌아오는 엔딩)는 이번 버전에서 적용하지 않는다.

1. **CONTACT / S16–S17:** 빨간 전화기가 울리고 수화기를 클릭하면 메모 작성 UI가 열린다. 전송 여부와 관계없이 다음 장면으로 진행할 수 있다.
2. **S18 / Pull Back:** 수화기 및 폼이 닫히며 카메라가 천천히 뒤로 이동한다. 작업실 전체와 비어 있는 의자를 다시 보여준다.
3. **S19 / Brand Signature:** 3D 공간은 배경에 남고 VIN. / Vision Inside / Explore to Evolve. 타이포가 차례로 나타난다. 하단에 Explore Again / Back to Projects.

**핵심 UX 규칙:** 메시지 전송은 필수 완료 조건이 아니다. CONTACT를 이용하지 않는 방문자도 자연스럽게 엔딩에 도착한다. 전송에 실패하더라도 포트폴리오 이동이 막히면 안 된다.

- **빛 전환:** c4의 45% 지점부터 스크롤에 맞춰 왼쪽 위(8%, 6%)에서 빛이 번지고 끝에서 화면이 웜화이트로 덮인다. 끝까지 내리면 3D HOME을 그 뒤에 올리고, 3D가 실제로 그려지기 시작하면(최대 6초 대기) 0.25초 머문 뒤 1.4초 동안 걷힌다. 빛이 걷히는 동안 스크롤은 잠긴다.

### 6-1장 규칙 구현

- **첫 방문:** INTRO부터. 끝까지 보거나 Skip하면 `localStorage`(`vin-v3-intro-seen`)에 기억한다.
- **재방문:** INTRO 없이 S04. 오른쪽 위에 작은 "인트로 다시 보기" 버튼.
- **Skip:** 2.5초 뒤 오른쪽 아래에 낮은 대비로 나타난다. 누르면 0.8초 동안 빛이 차오른 뒤 S04.
- **되감기 없음:** S04로 넘어가면 INTRO를 화면에서 아예 내리고 스크롤을 0부터 다시 시작한다. 위로 스크롤해도 INTRO는 나오지 않는다(다시 보기 버튼으로만).
- **INTRO 생략 주소:** `/work/...`, `/quick`. *지금은 두 주소의 실제 화면이 없어 S04로 간다(구현 단계 7에서 연결).*
- **움직임 줄이기:** 시퀀스 대신 마지막 프레임 정지 이미지를 1.2초 보여주고 0.8초 페이드로 S04.
- **개발용:** 왼쪽 위에 프레임 번호·클립·진행률·불러온 수(`INTRO_DEV_HUD`, 배포 빌드에서는 꺼짐). `?intro=1`이면 재방문이어도 INTRO 재생.

### S04 카메라 (k5 구도에 맞춤)
